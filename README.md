## Selected Projects

### [Cross-Border Public Transportation Information Service](https://github.com/YI-CHENLIN1204/travel-info-assistant)

A multi-city transportation information service integrating official data sources from Taiwan, Tokyo, Hong Kong, Singapore, and other external providers.

- Normalizes heterogeneous API responses behind a unified backend
- Uses shared caching, rate limiting, and quota-aware fallback strategies
- Built with Vue 3, TypeScript, ASP.NET Core Web API, PostgreSQL, Redis, and Docker

### Travel Document OCR & Data Management System

An internal travel-agency workflow system for reducing repetitive document data entry.

- Browser-side OCR and image preprocessing
- Structured field validation and traveler matching
- Document-version management with human-in-the-loop review
- Built with Vue 3, TypeScript, ASP.NET Core, PostgreSQL, and PaddleOCR.js / PP-OCRv5

> The repository is currently private while privacy-sensitive test material and document-handling workflows are under review.

> Source code is not publicly shared because the project involves collaboration data and project constraints.
