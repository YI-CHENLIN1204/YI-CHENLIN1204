目前就讀於 **國立雲林科技大學資訊管理系二技**，五專就讀 **國立臺中科技大學資訊工程科**。

- 🎓 下一階段：希望透過研究所訓練，強化問題定義、研究設計、實驗驗證與系統評估能力

## 精選專案

### 🚆 [跨國公共運輸資訊整合服務](https://github.com/YI-CHENLIN1204/travel-info-assistant)
**Cross-Border Public Transportation Information Service**

整合不同國家與城市的公共運輸資料來源，將異質 API 資料轉換為統一格式，並透過快取、限流與額度管理降低重複請求與外部服務成本。

**目前涵蓋：** 台灣、東京、香港、新加坡等交通資料來源  
**技術：** Vue 3 · TypeScript · ASP.NET Core Web API · PostgreSQL · Redis · REST API · Docker

---

### 🪪 旅客證件 OCR 辨識與資料管理系統
**Travel Document OCR & Data Management System**

源自旅行社實際證件建檔流程，透過瀏覽器端 OCR、資料驗證、旅客比對、證件版本管理與人工覆核，降低重複輸入與資料錯誤。

**技術：** Vue 3 · TypeScript · ASP.NET Core · PostgreSQL · PaddleOCR.js / PP-OCRv5 · Docker  
**狀態：** 持續開發中｜Repository 目前為 Private，以避免隱私敏感測試資料被公開。

---

### 🏗️ 營造工程量價估算與異常偵測系統
**Construction Cost Estimation & Anomaly Detection System**

產學合作專案，參與資料標準化、相似案例分析、量價估算與異常偵測，將歷史工程資料轉化為可供人工覆核與判斷的參考依據。

**技術：** C# · ASP.NET Core · EF Core · PostgreSQL · Vue · REST API · Docker  
**說明：** 因涉及合作資料與專案限制，不公開原始碼。

---

### 🚁 無人機結合影像辨識
**Drone-Based Image Recognition System**

五專畢業專題，擔任專題組長。整合影像辨識、嵌入式控制、無線通訊、3D 建模與實體硬體除錯，完成小型四軸無人機系統。
